# results/

Simulation outputs and figures

Contains outputs generated by running code in `main`. Plots are saved as PNG and tables as CSV. File names start with the layout prefix (`S_BR_hthp`, `S_IR_hthp`, `TES_BR_hthp`, `TES_IR_hthp`); figures that compare layouts start with `all_hthp_`.

- `paper/`: tables and plots adopted in the paper.
- `paper/validation/`: results used explicitly for model verification and validation.
