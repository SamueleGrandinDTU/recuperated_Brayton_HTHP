# results/

Simulation outputs and figures

Contains outputs generated by running code in `main` delivering numerical experiments and simulations

- `figs/`: figures generated directly from code.
- `final/`: curated results used in final manuscript, papers or presentations.
- `temporary/`: intermediate or exploratory outputs.
- `validation/`: (if relevant) results used explicitly for model verification and validation.

Results files should be organized with clear naming conventions, e.g. by case or simulation date
