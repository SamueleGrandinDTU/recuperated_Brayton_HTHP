# examples/

Minimal executable usage examples

Provides short, executable examples demonstrating how to use the research software for typical use cases or reference simulations. They run the same way as the scripts in `main/` (repository root as working directory), constituting a smaller part of its workflow.

The simulation of single layouts (`\layouts`) or the comparison of layouts (`hthp_comparison.py`) can be run. Also, examples of operational strategies (`operational_strategies_comparison.py`) is provided.
